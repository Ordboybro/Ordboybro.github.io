# Security Policy

This repository contains the ORDBOY portfolio site and its static frontend.

## Reporting a vulnerability

Please report security-sensitive issues privately through GitHub rather than publishing exploit details in a public issue. Include the affected page/file, browser, reproduction steps and impact. Do not include credentials, private data or other secrets.

## Security expectations

- Keep user-controlled content safely rendered.
- Avoid introducing unnecessary third-party runtime scripts.
- Keep external integrations explicit and documented.
- Do not commit credentials, API keys or service-role secrets.
- Keep Supabase/server-side credentials out of client-side source code.
