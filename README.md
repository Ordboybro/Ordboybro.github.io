# Emoji Drops

> Игровой веб-интерфейс с кейсами, рулетками, Live Drops, профилем и апгрейдом предметов.

## Возможности

- 📦 Открытие кейсов и множественное открытие
- 🎰 Отдельная плавная рулетка для каждого открываемого кейса
- ⚡ Быстрый режим открытия
- 🔴 Live Drops с ограниченным потоком элементов
- 👤 Профиль, инвентарь и Best Drop
- ⚙️ Настройки аккаунта и статистика
- 🚀 Апгрейд предметов с множителями x1.5 / x2 / x3 / x5
- 📱 Адаптивный интерфейс для ПК и телефона
- 💾 Локальное сохранение состояния пользователя

## Технологии

HTML, CSS и JavaScript без тяжёлого frontend-фреймворка.

## Запуск

Проект — статический сайт. Его можно открыть локально или разместить через GitHub Pages.

## Структура

- `index.html` — основная разметка и стили
- `js/data.js` — данные кейсов и предметов
- `js/app-v2.js` — основной runtime сайта
- `logo.png` — логотип Emoji Drops

## Статус

Проект находится в активной разработке и полируется по функциональности, производительности и UX.
